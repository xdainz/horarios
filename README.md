# HorarioDUOC

Generador de horarios para estudiantes de DUOC UC. Sube el Excel de horarios
de tu sede y genera **todas las combinaciones de horario sin topes** para tu
carrera, jornada y nivel, ordenadas según tus preferencias (sin ventanas,
días libres, clases temprano o tarde). También muestra los optativos
compatibles con cada horario generado.

Todo corre en el navegador: el archivo nunca se sube a ningún servidor.

## Uso

1. Descarga el Excel de horarios de tu sede.
2. Arrastra el archivo `.xlsx` a la página.
3. Elige carrera, jornada y nivel.
4. Selecciona tus asignaturas y (opcional) cómo prefieres tu horario.
5. Clickea en "Generar Horario"
